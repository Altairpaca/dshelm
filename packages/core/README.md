# @dshelm/core

Runtime-validated policy, configuration, model-routing, and Resolution Trace primitives for DSHelm.

`@dshelm/core` is intentionally independent of DeepSeek Harness packages. It owns the policy kernel and deterministic resolution contract; DSH execution belongs in `@dshelm/dsh` and the DSH ecosystem.

> **Alpha API:** public types and policy schema may still change before a stable release. Compatibility claims should follow the repository's evidence rules rather than informal model rankings.

See the [project README](../../README.en.md), [architecture](../../docs/ARCHITECTURE.md), and [contribution guide](../../CONTRIBUTING.md).
