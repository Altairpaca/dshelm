# @dshelm/model-knowledge

Evidence-backed model capability knowledge used by DSHelm routing.

This package stores structured capability evidence and confidence used by the resolver. Its metadata is a maintained routing input, not a general-purpose model leaderboard and not a claim that one model is globally better than another.

Model/provider changes should include a source or reproducible runtime evidence and must not override hard runtime/authentication constraints.

See the [project README](../../README.en.md), [contribution guide](../../CONTRIBUTING.md), and [`compatibility.json`](../../compatibility.json).
